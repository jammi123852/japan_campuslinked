# CampusLinked

규슈산업대학교(일본) 학생을 위한 비공식 캠퍼스 앱입니다. 시간표·일정, 수업 후기와 학생 게시판, 학교 공식 정보 검색, 졸업 요건 확인, 수강 계획을 한 앱에서 합니다. 한국어와 일본어를 전환할 수 있습니다.

九州産業大学の学生向け非公式キャンパスアプリです。時間割・予定、授業レビューと掲示板、公式情報の検索、卒業要件の確認、履修計画をひとつのアプリで扱います。韓国語と日本語を切り替えられます。

> 학교 공식 앱이 아닙니다. 학교 색·로고를 쓰지 않습니다.

## 기술 스택

- Expo SDK 58 · Expo Router · TypeScript · React Native (웹·iOS·Android 같은 코드)
- 개인 데이터(시간표·일정·이수 기록)는 기기 안 저장(AsyncStorage / 웹 localStorage)
- 게시판·후기 공유 서버: Node.js + SQLite (`server/`)
- 시간표 사진 인식: 기기 안 OCR(Google ML Kit, 개발 빌드 한정)

## 공개본에서 빠진 것

- **AI 기능을 쓰는 API 키는 들어 있지 않습니다.** AI 관련 코드는 키가 없으면 꺼진 상태로 동작합니다.
- **학교 공식자료 데이터는 들어 있지 않습니다.** 재배포 허가를 확인하지 못해 공개 최소본(학교 구조·공식 링크)만 씁니다.
- 실제 학생의 수강 이력·게시글·DB·로그는 들어 있지 않습니다. 샘플 강의·후기는 모두 가상입니다.

## 실행

```bash
npm install
npx expo start --web     # 브라우저
npm run server           # 게시판 공유 서버 (선택)
npm test                 # 순수 로직 테스트
```
